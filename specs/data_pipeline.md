# Spec — UltraData → StarCoder2 `.bin` shards (code training)

## Goal
Convert `/mnt/file_drive/data/ultradata` (UltraData-Code, 1129 parquet files, 1.2 TB) into
`uint16` token shards consumable by `x-small/train_san.py`, tokenized with
**`bigcode/starcoder2-7b`** (vocab **49152**) — *not* SmolLM2 and *not* cosmo2.

## Inputs (facts)
- Files: `UltraData-Code-L2-<lang>-part-XXXXX-of-YYYYY.parquet`
  and `UltraData-Code-L3-<lang>-part-XXXXX-of-YYYYY.parquet` (11 languages per level).
- **L2 columns:** `uuid, repo_name, relative_path, content, category, algo_rel_score, quality_score`
- **L3 columns:** `uuid, content, content_format, raw_content, task, analysis, solution, test, full_content, full_content_format`
- Scores ship in the parquet (model-generated by `openbmb/UltraData-Code-L2-Classifier`:
  Qwen3-Embedding-0.6B + role/relevance/quality heads). No re-classification needed.

## Outputs
- `/mnt/file_drive/data/_shards_code_easy/train-NNNNNN.bin`
- `/mnt/file_drive/data/_shards_code_medium/train-NNNNNN.bin`
- `/mnt/file_drive/data/_shards_code_hard/train-NNNNNN.bin`
- `/mnt/file_drive/data/_shards_code_gold/codegold-NNNNNN.bin`
- Format: little-endian `uint16`, continuous token stream (no per-doc padding; the datasets
  chunk at `seq_len`), `TOKENS_PER_SHARD = 256_000_000`, EOS appended between documents.

## Filters & tiering
- `quality_score >= 3.0` (quality floor).
- `algo_rel_score >=` per-language floor (0.5–0.85; **Python floor = 0.0**).
- De-duplicate on `uuid` (and optionally on content hash).
- Tier from score quantiles (per language, to avoid language bias):
  easy = lower quantiles, medium = middle, hard = upper; `gold` = L3 `full_content`
  (or top-quantile L2). Keep the two channels (L2 → CPT, L3 → mid-train/SFT).
- Optional `category` weighting (boost ALGO, down-weight TOOL/CONFIG) — record in metadata,
  don't drop.

## Tokenization
- `AutoTokenizer.from_pretrained("bigcode/starcoder2-7b")`, `add_special_tokens=False`.
- Append EOS (id = tokenizer.eos_token_id) between documents.
- `np.array(ids, dtype=np.uint16)`; assert `int(ids.max()) < 49152` before writing.
- Stream, never hold a whole language in RAM.

## Parallelism / runtime
- One worker process per `(level, language)` (22 workers), or shard the file list across `-j N`.
- Interpreter: `/home/kenpeter/work/fly_brain/.venv/bin/python` (has pyarrow); verify `transformers`.
- Read parquet with `pyarrow.parquet.ParquetFile(...).iter_batches(batch_size=...)`.

## Wiring into training
- `x-small/train_san.py` `SHARD_DIRS` currently points at `/home/kenpeter/work/data/_shards_code_*`.
  Either repoint those paths to `/mnt/file_drive/data/_shards_code_*` or symlink the four dirs.
  Shards are ~0.8 TB at 400B tokens, so they must live on `/mnt` (12 TB free), not `/`.

## Smoke test (must pass before the full run)
1. Tokenize ONE parquet file end-to-end.
2. Assert: dtype `uint16`, `max(id) < 49152`, `len(tokens) > 0`.
3. Decode a sample back to text to confirm round-trip sanity.
4. Print tokens/byte ratio and docs/s so we can estimate the full 1.2 TB runtime.

## Deliverable
`tokenize_ultradata.py` (CLI: `--levels L2,L3 --langs ... --out-root /mnt/file_drive/data
--workers N --smoke`), plus a short `README`/`--help`, and a logged smoke test.
